Curso de programación

Java desde cero

Aprende los fundamentos del lenguaje Java y desarrolla tus primeras soluciones mediante conceptos de programación estructurada y orientada a objetos.

Este curso está diseñado para estudiantes que desean comenzar a programar utilizando uno de los lenguajes más utilizados en el desarrollo de software.

¿Qué aprenderás?

Al finalizar el curso podrás desarrollar programas básicos en Java y comprender los principales conceptos de la programación orientada a objetos.

  • Comprender la sintaxis básica de Java.
  • Utilizar variables y tipos de datos.
  • Crear estructuras condicionales y repetitivas.
  • Crear y utilizar métodos.
  • Comprender las clases y los objetos.
  • Aplicar los principios básicos de la programación orientada a objetos.
  • Desarrollar programas sencillos utilizando Java.

Temario

El curso está organizado en módulos que permiten avanzar desde los fundamentos de programación hasta los conceptos básicos de programación orientada a objetos.

Módulo 1: Introducción a Java

Conoce el lenguaje Java, su funcionamiento y las herramientas necesarias para comenzar a desarrollar programas.

  • ¿Qué es Java?
  • Características de Java
  • JDK, JRE y JVM
  • Instalación del entorno
  • Primer programa en Java
Módulo 2: Variables y tipos de datos

Aprende a almacenar y manipular información utilizando variables y diferentes tipos de datos.

  • Variables
  • Tipos de datos primitivos
  • String
  • Constantes
  • Operadores
Módulo 3: Control de flujo

Aprende a controlar la ejecución de un programa mediante condiciones y estructuras repetitivas.

  • if
  • if-else
  • switch
  • while
  • do-while
  • for
Módulo 4: Métodos y arreglos

Aprende a organizar el código mediante métodos y a trabajar con colecciones básicas de datos.

  • Declaración de métodos
  • Parámetros
  • Valores de retorno
  • Arreglos
  • Recorrido de arreglos
Módulo 5: Programación orientada a objetos

Introducción al paradigma orientado a objetos y a los elementos principales utilizados para construir aplicaciones en Java.

  • Clases
  • Objetos
  • Atributos
  • Métodos
  • Constructores
  • Encapsulamiento
Módulo 6: Principios de POO

Conoce los principales conceptos que permiten crear programas orientados a objetos más organizados y reutilizables.

  • Encapsulamiento
  • Herencia
  • Polimorfismo
  • Abstracción
  • Interfaces

Conceptos fundamentales

Java
Lenguaje de programación orientado a objetos utilizado para desarrollar diferentes tipos de aplicaciones.
Variable
Espacio de memoria asociado con un nombre que permite almacenar un valor durante la ejecución de un programa.
Clase
Estructura que define las características y comportamientos que tendrán determinados objetos.
Objeto
Instancia de una clase que posee un estado y comportamientos definidos por ella.
Método
Bloque de código que contiene instrucciones para realizar una tarea específica.
Encapsulamiento
Principio de programación orientada a objetos que permite controlar el acceso al estado interno de los objetos.

Ruta de aprendizaje

Sigue este orden para construir una base sólida en programación con Java:

  1. Conocer el lenguaje Java y su entorno.
  2. Aprender variables, tipos de datos y operadores.
  3. Utilizar estructuras condicionales.
  4. Trabajar con ciclos y estructuras repetitivas.
  5. Crear métodos para organizar el código.
  6. Trabajar con arreglos.
  7. Comprender clases y objetos.
  8. Aplicar los principios básicos de POO.

Proyecto final

Para finalizar el curso desarrollarás un programa sencillo en Java aplicando los conocimientos adquiridos durante los diferentes módulos.

Ver requisitos del proyecto
  1. Crear un proyecto Java correctamente estructurado.
  2. Utilizar variables y tipos de datos.
  3. Utilizar estructuras condicionales.
  4. Utilizar al menos una estructura repetitiva.
  5. Crear métodos para organizar el programa.
  6. Utilizar clases y objetos.
  7. Aplicar encapsulamiento.
