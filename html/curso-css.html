Curso de desarrollo web

CSS desde cero

Aprende a utilizar CSS para diseñar páginas web, controlar su apariencia y mejorar la presentación de tus proyectos.

Este curso está pensado para estudiantes que ya conocen los fundamentos básicos de HTML y desean comenzar a crear interfaces web más atractivas.

¿Qué aprenderás?

Al finalizar el curso podrás utilizar CSS para controlar la apariencia y distribución de los elementos de una página web.

  • Comprender qué es CSS y cómo funciona.
  • Aplicar estilos a elementos HTML.
  • Utilizar selectores y propiedades CSS.
  • Trabajar con colores, fuentes y fondos.
  • Comprender el modelo de caja.
  • Crear diseños utilizando Flexbox.
  • Introducir conceptos de diseño responsive.

Temario

El curso está organizado en módulos para aprender CSS de manera progresiva.

Módulo 1: Introducción a CSS

Conoce el funcionamiento de CSS y las diferentes formas de aplicar estilos a un documento HTML.

  • ¿Qué es CSS?
  • CSS3
  • CSS interno
  • CSS externo
  • CSS en línea
Módulo 2: Selectores y propiedades

Aprende a seleccionar elementos HTML y modificar sus características mediante propiedades CSS.

  • Selectores de elemento
  • Selectores de clase
  • Selectores de ID
  • Propiedades y valores
  • Herencia
  • Especificidad
Módulo 3: Colores y tipografía

Aprende a modificar la apariencia visual del contenido mediante colores y fuentes.

  • Colores
  • Fondos
  • Fuentes
  • Tamaño del texto
  • Alineación
  • Espaciado
Módulo 4: Modelo de caja

Comprende cómo CSS calcula el tamaño y el espacio que ocupa cada elemento.

  • Content
  • Padding
  • Border
  • Margin
  • Width y height
  • Box sizing
Módulo 5: Diseño con Flexbox

Aprende a organizar elementos dentro de un contenedor utilizando Flexbox.

  • Flex container
  • Flex direction
  • Justify content
  • Align items
  • Gap
  • Flex wrap
Módulo 6: Diseño responsive

Aprende los conceptos básicos necesarios para adaptar una página web a diferentes tamaños de pantalla.

  • Diseño responsive
  • Media queries
  • Unidades relativas
  • Adaptación a dispositivos móviles

Conceptos fundamentales

CSS
Lenguaje utilizado para definir la presentación y apariencia de los documentos HTML.
Selector
Patrón utilizado para seleccionar los elementos HTML a los que se aplicarán determinados estilos.
Propiedad
Característica de CSS que permite modificar un aspecto específico de un elemento.
Valor
Dato que determina cómo se aplicará una propiedad CSS.
Flexbox
Modelo de diseño de CSS utilizado para organizar elementos dentro de un contenedor de manera flexible.

Ruta de aprendizaje

Sigue este orden para avanzar progresivamente en el aprendizaje de CSS:

  1. Comprender qué es CSS y su relación con HTML.
  2. Aprender a utilizar selectores.
  3. Conocer propiedades y valores CSS.
  4. Trabajar con colores, fuentes y fondos.
  5. Comprender el modelo de caja.
  6. Crear diseños utilizando Flexbox.
  7. Adaptar páginas mediante diseño responsive.
  8. Crear un proyecto web utilizando HTML y CSS.

Proyecto final

Para finalizar el curso crearás el diseño visual de una página web utilizando HTML y CSS.

Ver requisitos del proyecto
  1. Utilizar un documento HTML estructurado.
  2. Crear una hoja de estilos CSS externa.
  3. Utilizar selectores y propiedades CSS.
  4. Aplicar colores y tipografías.
  5. Utilizar el modelo de caja.
  6. Utilizar Flexbox en alguna sección.
  7. Adaptar el diseño para dispositivos móviles.
