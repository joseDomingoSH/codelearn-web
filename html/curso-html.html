Curso de desarrollo web

HTML desde cero

Aprende los fundamentos de HTML y descubre cómo crear y estructurar correctamente una página web.

Este curso está diseñado para personas que comienzan desde cero y desean adquirir una base sólida en desarrollo web.

¿Qué aprenderás?

Al finalizar el curso tendrás los conocimientos necesarios para crear la estructura básica de una página web utilizando HTML5.

  • Comprender qué es HTML y para qué se utiliza.
  • Conocer la estructura de un documento HTML.
  • Utilizar etiquetas y atributos correctamente.
  • Crear títulos, párrafos, enlaces y listas.
  • Incorporar imágenes y contenido multimedia.
  • Utilizar elementos semánticos de HTML5.

Temario

El curso está dividido en módulos para facilitar el aprendizaje progresivo.

Módulo 1: Introducción a HTML

Conoce los conceptos fundamentales de HTML y la función que desempeña dentro del desarrollo web.

  • ¿Qué es HTML?
  • HTML5
  • Elementos y etiquetas
  • Atributos
  • Estructura de un documento HTML
Módulo 2: Texto y estructura

Aprende a organizar el contenido textual de una página mediante diferentes elementos.

  • Encabezados
  • Párrafos
  • Énfasis
  • Citas
  • Comentarios
Módulo 3: Enlaces y listas

Aprende a conectar diferentes páginas y a organizar información mediante listas.

  • Enlaces
  • Listas ordenadas
  • Listas desordenadas
  • Listas de descripción
Módulo 4: Imágenes y multimedia

Aprende a incorporar contenido multimedia dentro de una página web.

  • Imágenes
  • Audio
  • Video
  • Contenido externo
Módulo 5: Formularios

Conoce los elementos básicos utilizados para recopilar información de los usuarios.

  • Formularios
  • Campos de texto
  • Botones
  • Casillas de selección
  • Opciones
Módulo 6: HTML semántico

Aprende a utilizar elementos que describen el significado y la función del contenido de una página.

  • header
  • nav
  • main
  • section
  • article
  • aside
  • footer

Conceptos fundamentales

HTML
Lenguaje de marcado utilizado para estructurar el contenido de las páginas web.
Etiqueta
Elemento utilizado para indicar al navegador cómo debe interpretar una parte del documento.
Atributo
Característica adicional que proporciona información o modifica el comportamiento de un elemento HTML.
Elemento
Componente de un documento HTML formado generalmente por una etiqueta de apertura, contenido y una etiqueta de cierre.
HTML semántico
Uso de elementos HTML que permiten describir claramente el propósito del contenido.

Ruta de aprendizaje

Te recomendamos seguir este orden para avanzar progresivamente en el curso:

  1. Comprender qué es HTML.
  2. Conocer la estructura básica de un documento HTML.
  3. Aprender a utilizar etiquetas y atributos.
  4. Crear contenido mediante textos, enlaces y listas.
  5. Incorporar imágenes y contenido multimedia.
  6. Crear formularios básicos.
  7. Aplicar HTML semántico.
  8. Crear una página web como proyecto final.

Proyecto final

Para finalizar el curso crearás una página web utilizando los conocimientos adquiridos.

Ver requisitos del proyecto
  1. Crear un documento HTML5 válido.
  2. Utilizar encabezados y párrafos.
  3. Incorporar enlaces.
  4. Utilizar al menos una lista.
  5. Agregar una imagen.
  6. Utilizar elementos semánticos.
  7. Crear un formulario básico.
