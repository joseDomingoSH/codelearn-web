Recursos educativos

Complementa tu aprendizaje mediante recursos de consulta, ejercicios y herramientas relacionadas con los cursos de CodeLearn.

Recursos disponibles

Documentación de HTML

Consulta información sobre etiquetas, atributos, estructura de documentos y elementos semánticos de HTML.

¿Qué puedes aprender?
  • Estructura básica de HTML
  • Elementos semánticos
  • Enlaces e imágenes
  • Formularios

Recursos de CSS

Aprende a mejorar la presentación de tus páginas mediante propiedades, selectores y técnicas de diseño con CSS.

¿Qué puedes aprender?
  • Selectores y propiedades
  • Colores y tipografía
  • Modelo de caja
  • Flexbox y Grid

Material de Java

Refuerza los fundamentos de Java mediante conceptos relacionados con variables, estructuras de control y programación orientada a objetos.

¿Qué puedes aprender?
  • Variables y tipos de datos
  • Condicionales y ciclos
  • Clases y objetos
  • Programación orientada a objetos

Herramientas recomendadas

Editor de código
Utiliza un editor de código para escribir, organizar y modificar tus proyectos.
Navegador web
Permite visualizar y probar las páginas web desarrolladas durante los cursos.
Entorno de desarrollo
Utiliza un entorno de desarrollo para crear y ejecutar aplicaciones desarrolladas con Java.

Consejo de aprendizaje

No te limites a leer la teoría. Escribe código, experimenta con diferentes soluciones y corrige los errores que encuentres durante la práctica.
